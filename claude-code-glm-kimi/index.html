How it works

One key, pasted once

Paste your key in setup

In the Farcall window, Pick your AI takes a Z.ai (GLM) or Moonshot (Kimi) API key. It goes into your computer's secret store and never to the phone.

Pick the provider per session

Starting a session on the phone, choose Claude, Claude · GLM or Claude · Kimi. Farcall starts Claude Code with that provider's address and your key; your normal terminal setup is left alone.

Same Claude Code, same approvals

Replies stream to your phone, and each command or file edit asks first: Allow or Deny. Photos and files go straight into the chat.

Side by side

Put Claude and GLM, or GLM and Kimi, in one chat: they answer the same question side by side and can discuss each other's answers.

Providers

What you can run

Claude Code on your Claude login, on Z.ai's GLM (GLM-5.3 as of October 2026), on Moonshot's Kimi (Kimi K3), or on Gemini through OpenRouter (preview). Codex on your OpenAI login (preview). Anthropic's Remote Control accepts only Anthropic's own API; Farcall works with all of these, with nothing to keep open on your computer.

Quickstart

Get started

  1. Install Farcall on the computer.
    Mac (Terminal): curl -fsSL https://github.com/eamon831/farcall-releases/releases/latest/download/install.sh | bash
    Windows (PowerShell): irm https://github.com/eamon831/farcall-releases/releases/latest/download/install.ps1 | iex
    Linux (x64): curl -fsSL https://github.com/eamon831/farcall-releases/releases/latest/download/install-linux.sh | bash
  2. Follow the setup in the Farcall window: sign in with Google, pick your AI (sign in to Claude or paste a key), choose your projects folder, and connect your phone. Farcall installs Claude Code if it's missing.
  3. Install the Android app from the QR code in setup and sign in with the same Google account. Your computer shows up by itself: no code to type.
FAQ

Questions

Can Claude Code use GLM or Kimi instead of Claude?

Yes. Z.ai and Moonshot both offer an Anthropic-compatible API, so Claude Code can run on GLM or Kimi when it is pointed at their address with your key. Farcall does that for you per session: paste the key once in setup and pick Claude · GLM or Claude · Kimi when you start a session.

Do I need a Claude subscription to use it with GLM or Kimi?

No. A Z.ai or Moonshot API key is enough. Farcall installs Claude Code during setup if it is missing.

Where is my API key kept?

On your computer, in the system's secret store: the Mac keychain, Windows Credential Manager, or the Linux keyring. Farcall reads it when a session starts and never sends it to the phone.

Can I mix providers?

Yes. Each session picks its own: one on your Claude login, one on GLM, one on Kimi, Codex on OpenAI. You can also put two or three agents in one chat and compare their answers.

Does Anthropic's Remote Control work with GLM or Kimi?

No. Remote Control accepts only Anthropic's own API. Farcall works with GLM, Kimi and OpenRouter keys as well as your Claude login.

Is there an iPhone app?

Not yet: the phone app is Android only for now.
