How it works

Codex on your computer, steered from your phone

Your ChatGPT sign-in

No API key: Codex uses its own sign-in, and Farcall's setup offers it. Pick Codex when you start a session on the phone.

Allow or Deny

When Codex wants to run a command or change a file, your phone shows it first. Tap Allow and it keeps going.

Codex and Claude Code together

Run Codex in one session and Claude Code (on Claude, GLM, Kimi or Gemini) in another, or put them in one chat to answer side by side.

Nothing to keep open

Farcall runs as a background service on Mac, Windows or Linux. Your phone reaches it over a private, encrypted network built into Farcall; Farcall's server only signs your devices in.

Quickstart

Get started

  1. Install the Codex CLI on the computer, if it isn't there yet.
  2. Install Farcall on the computer.
    Mac (Terminal): curl -fsSL https://github.com/eamon831/farcall-releases/releases/latest/download/install.sh | bash
    Windows (PowerShell): irm https://github.com/eamon831/farcall-releases/releases/latest/download/install.ps1 | iex
    Linux (x64): curl -fsSL https://github.com/eamon831/farcall-releases/releases/latest/download/install-linux.sh | bash
  3. Follow the setup in the Farcall window: sign in with Google, pick your AI (choose ChatGPT · Codex and sign in), choose your projects folder, and connect your phone.
  4. Install the Android app from the QR code in setup and sign in with the same Google account. Your computer shows up by itself: no code to type.
FAQ

Questions

Can I use Codex from my phone?

Yes. Codex runs on your own computer, signed in to your ChatGPT account, and Farcall gives you an Android app to drive it: start a session in a project, read replies as they stream, and allow or deny each command and file change.

How is this different from OpenAI's Codex mobile?

OpenAI's remote connections reach the ChatGPT or Codex app on a Mac or Windows computer and go offline when that app closes. Farcall runs as a background service on Mac, Windows or Linux, so nothing has to stay open, and it puts Codex and Claude Code side by side in one app.

Do I need an OpenAI API key?

No. Codex uses its own ChatGPT sign-in, and Farcall's setup offers that sign-in for you. Install the Codex CLI on the computer first; Farcall finds it.

Can Codex and Claude Code work in the same chat?

Yes. Put two or three agents in one chat, for example Codex and Claude Code: they answer side by side and can discuss each other's answers.

Is my code sent to a server?

No. Your phone reaches your computer over a private, encrypted network built into Farcall. Farcall's server only signs your devices in and helps them find each other; your code and chats stay on your machines and your AI provider.

Is there an iPhone app?

Not yet: the phone app is Android only for now.
