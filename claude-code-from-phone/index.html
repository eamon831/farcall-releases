Use Claude Code from your phone.

How it works

Your computer does the work, your phone steers

Start a session in a project

Pick a project folder on your computer and an AI, then type what you want. Replies stream in as Claude Code writes them.

Approve every command

When Claude Code wants to run a command or edit a file, your phone asks first: Allow or Deny. You get a notification when it's waiting for you.

Send photos and files

Screenshot a bug and send it into the chat. The agent reads the code and logs on your computer and tells you what went wrong.

Your code never passes our server

Your phone reaches your computer over a private, encrypted network built into Farcall. Chats and code stay on your machines and your AI provider.

Providers

Quickstart

Get started

  1. Install Farcall on the computer.
    Mac (Terminal): curl -fsSL https://github.com/eamon831/farcall-releases/releases/latest/download/install.sh | bash
    Windows (PowerShell): irm https://github.com/eamon831/farcall-releases/releases/latest/download/install.ps1 | iex
    Linux (x64): curl -fsSL https://github.com/eamon831/farcall-releases/releases/latest/download/install-linux.sh | bash
  2. Follow the setup in the Farcall window: sign in with Google, pick your AI (sign in to Claude or paste a key), choose your projects folder, and connect your phone. Farcall installs Claude Code if it's missing.
  3. Install the Android app from the QR code in setup and sign in with the same Google account. Your computer shows up by itself: no code to type.
FAQ

Questions

Can I use Claude Code from my phone?

Yes. Claude Code keeps running on your own computer, and Farcall gives you an Android app to drive it: start a session in a project, read replies as they stream, and approve or deny each command or file edit.

Does Claude Code run on the phone?

No. It runs on your Mac, Windows PC or Linux machine, with your files, tools and logins. The phone is the remote: you type what you want and tap Allow or Deny.

Can I use Claude Code on GLM or Kimi from my phone?

Yes. Claude Code in Farcall can run on your Claude login, on Z.ai's GLM, on Moonshot's Kimi, or on Gemini through OpenRouter (preview). You pick per session.

Is my code sent to a server?

No. Your phone reaches your computer over a private, encrypted network built into Farcall. Farcall's server only signs your devices in and helps them find each other; your code and chats stay on your machines and your AI provider.

Is there an iPhone app?

Not yet: the phone app is Android only for now.

Is Farcall free?

Yes, Farcall itself is free to download. You pay your AI provider as you normally would.
